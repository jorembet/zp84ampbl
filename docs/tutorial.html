Instalasi

Dependencies

  • Linux dengan X11 (libX11)
  • C compiler (gcc/cc)
  • libm (math library)

Build

git clone <repo-url> cd zp84-dsp make

Install

sudo ./scripts/install-udev.sh ./scripts/install-app.sh
Narasi
"Install dependencies, build dengan make, install udev rules dan aplikasi."

Menjalankan Aplikasi

./build/zp84gui --read-dsp

Aplikasi membaca seluruh 1934 parameter ID dari amplifier.

Opsi UI Scale

./build/zp84gui --read-dsp --scale 1.5

Skala: 0.75 - 2.5

Narasi
"Pastikan amplifier terhubung via USB, lalu jalankan aplikasi."

Tampilan Utama

Kontrol EQ

  • Drag fader — atur gain band
  • Klik kolom EQ — pilih band, lihat F/Q/G
  • Klik angka — edit nilai manual
  • Reset EQ — ratakan semua gain
  • Restore EQ — kembalikan nilai sebelum reset
Narasi
"Setiap channel memiliki 31-band graphic EQ. Drag fader untuk atur gain, klik kolom untuk pilih band."

Crossover

Panel crossover — HPF/LPF Type, Oct, dan Frequency

KontrolPilihan
HPF/LPF TypeButterworth, Bessel, Linkwitz-Riley
HPF/LPF Oct6, 12, 18, 24, 30, 36, 42, 48 dB/oct, OFF
HPF/LPF Frequency10 - 23000 Hz
Narasi
"Panel crossover mengatur filter high-pass dan low-pass per channel."

Time Alignment

Diagram posisi speaker — drag untuk mengatur delay

  • Pilih mode Mobil atau Ruangan
  • Drag angka channel untuk atur posisi speaker
  • Drag titik P untuk posisi dengar
  • Jarak/Delay > Atur lebar — kalibrasi skala
  • Klik Terapkan Delay untuk kirim ke DSP
Narasi
"Time alignment mengatur delay per channel agar suara tiba bersamaan."

Mixer Matrix

Mixer — matriks routing 8 output vs input sources

  • Klik ON/OFF untuk enable/disable routing
  • Klik angka persen untuk edit gain
  • Drag slider untuk preview
Narasi
"Mixer mengatur routing input ke output dengan gain control per channel."

Preset & Memory

Memory — 8 slot preset lokal dengan file .scene

Simpan Preset

  1. Klik Simpan pada slot
  2. Masukkan nama (1-24 karakter)
  3. Klik Simpan preset atau Enter

Load Preset

  1. Klik Load pada baris preset
  2. Output di-mute selama penerapan
  3. Status mute dipulihkan setelah selesai
Narasi
"Menu Memory menyediakan 8 slot preset lokal."

Kontrol Tambahan

Link Pairs

Hubungkan CH1/2, 3/4, 5/6, 7/8

Lock Output

Kunci level, phase, mute, delay

Mute

Ikon speaker = mute channel

Input Volume

Level USB & Bluetooth 0-100

Noise Gate

Tingkat 0-20 (0 = OFF)

Reset Output

Reset channel ke default

Narasi
"Kontrol tambahan: link pairs, lock output, mute, input volume, noise gate."

./build/zpsniff find # cari device ./build/zpsniff ping # handshake ./build/zpsniff get --id 139 # baca parameter ./build/zpsniff snap -o snap.txt # snapshot semua ./build/zpsniff diff a.txt b.txt # bandingkan ./build/zpsniff dump -o dump.bin # dump semua
Narasi
